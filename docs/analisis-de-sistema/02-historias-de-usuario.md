# Fase 1 — Historias de usuario

### 1.5 Historias de usuario

Formato: *Como [actor], quiero [acción], para [beneficio].*

| ID | Historia |
|----|----------|
| HU01 | Como usuario de Telegram, quiero iniciar el bot desde un enlace, para recibir la información del programa que me interesa. |
| HU02 | Como administrador, quiero generar enlaces de ingreso con área, programa, origen y campaña, para saber de dónde llega cada persona sin preguntárselo. |
| HU03 | Como operador, quiero ver y buscar todos los contactos con filtros, para encontrar rápido a quien necesito. |
| HU04 | Como operador, quiero etiquetar contactos de forma individual o masiva, para clasificarlos por interés. |
| HU05 | Como administrador, quiero crear segmentos guardados combinando condiciones, para reutilizarlos en campañas. |
| HU06 | Como administrador, quiero crear una campaña con texto, imagen, PDF, enlaces y botones, y ver una vista previa, para enviarla con confianza. |
| HU07 | Como administrador, quiero programar el envío de una campaña, para que salga a la hora conveniente sin que yo esté presente. |
| HU08 | Como administrador, quiero que el sistema respete los límites de Telegram y reintente solo, para no ser bloqueado ni perder envíos. |
| HU09 | Como administrador, quiero que quienes bloquearon el bot queden marcados y excluidos, sin borrarlos, para no seguir enviándoles. |
| HU10 | Como administrador, quiero ver estadísticas por campaña, para medir resultados. |
| HU11 | Como operador, quiero abrir la ficha de un contacto con su historial, para entender su recorrido. |
| HU12 | Como administrador, quiero un dashboard simple, para conocer el estado de la base de un vistazo. |
| HU13 | Como administrador, quiero crear usuarios con roles Administrador y Operador, para repartir el trabajo con control de acceso. |
| HU14 | Como administrador, quiero conectar varios bots y verlos por separado, para manejar marcas o segmentos distintos desde un solo CRM. |
| HU15 | Como cliente, quiero recibir el código, accesos y respaldos, para no depender del desarrollador. |
